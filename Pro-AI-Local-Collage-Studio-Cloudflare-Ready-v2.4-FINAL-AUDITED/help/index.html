GETTING STARTED
DROP 2–9 PHOTOS, CHOOSE A QUICK LAYOUT, THEN SWITCH TO PRECISION WHEN YOU NEED PIXEL-LEVEL CONTROL.
COMPOSITION INTELLIGENCE
SMART COMPOSE compares image hierarchy, image-to-image rhythm, spacing, alignment, focal safety and the selected intent. The engine can reorder photos into a stronger composition without changing your source files.
IMAGE PROTECTION
NEVER CROP keeps the full image visible. SMART CROP uses the focal point while preserving the important part of the image. FREE CROP gives you direct crop control.
PROJECTS
PROJECTS ARE STORED LOCALLY WITH INDEXEDDB. SAVE PROJECT creates a .LOCALCOLLAGE file containing editable project data and its image files.
PRIVACY
LOCAL MODE processes image files in your browser. The studio does not require an image-upload server to create or export a collage.
EXPORT
PNG preserves transparency. JPEG needs an opaque background. WEBP can be used for compact web output. DPI is metadata; pixel dimensions determine image detail.
SMART COMMAND
PRESS SMART COMMAND OR CMD/CTRL + K. DESCRIBE A CHANGE IN PLAIN LANGUAGE. THE STUDIO PREVIEWS SAFE, REVERSIBLE ACTIONS BEFORE ANYTHING IS APPLIED. COMMON REQUESTS RUN LOCALLY WITH ZERO AI QUOTA; OPTIONAL AI IS ONLY USED WHEN THE LOCAL INTERPRETER CANNOT SAFELY MAP THE REQUEST.
