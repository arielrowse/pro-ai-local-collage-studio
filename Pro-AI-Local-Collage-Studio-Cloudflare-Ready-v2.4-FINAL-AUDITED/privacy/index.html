PRIVACY BY ARCHITECTURE

YOUR PHOTOS STAY WITH THE WORKFLOW.

This application is designed so the core collage editor can process image files in your browser without requiring an image-upload server.

LOCAL EDITING

Image decode, layout, composition, rendering, project editing and export run in the browser. Local project data uses browser storage such as IndexedDB when you enable autosave.

OPTIONAL VISION

On-device vision is optional. When enabled, the model/runtime is downloaded to the browser and inference is performed on-device. The app does not send the source image to our AI endpoint for vision.

OPTIONAL AI

External AI is optional. The studio sends compact structured project context and your request to the selected provider or configured edge route. Source image bytes are not included in that assistant request.

WHAT WE DON'T NEED

NO ACCOUNTCore editing does not require registration.
NO IMAGE UPLOADThe core editor does not require a central image-upload service.
NO PROJECT CLOUD SYNCProjects are local unless you deliberately export and share them yourself.
NO REQUIRED AILocal tools remain available when external AI is unavailable.
IMPORTANT: Your browser, operating system, Cloudflare infrastructure and optional third-party services can have their own logs, policies and telemetry. Review the relevant provider documentation when you enable optional services.
